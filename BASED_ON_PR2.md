# Основа проекта

ПР6 построена как продолжение приложенного пользователем проекта ПР2 `calc_web`.

Из исходного проекта сохранена предметная область «Библиотека», основные сущности Book/Author, исходные 20 книг, 8 авторов, параметры книг (ISBN, год, страницы, publisherId, authorIds, genreIds, количество экземпляров), а также логика списков, поиска, сортировки и пагинации.

Дальнейшие возможности добавлены по требованиям ПР6.
