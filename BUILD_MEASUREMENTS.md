# Измерения сборки для отчёта ПР6

Числа в таблицу нужно внести после сборки на вашем компьютере — они зависят от версии Flutter и окружения.

| Вариант | Размер build/web | Первая загрузка |
|---|---:|---:|
| Обычная release | заполнить после измерения | заполнить в DevTools |
| Release + --wasm | заполнить после измерения | заполнить в DevTools |
| Оптимизированная ПР6 | заполнить после измерения | заполнить в DevTools |

## Размер каталога в PowerShell

```powershell
[math]::Round(((Get-ChildItem build\web -Recurse -File | Measure-Object Length -Sum).Sum / 1MB), 2)
```

## Время первой загрузки

Откройте Chrome DevTools → Network, включите Disable cache, очистите список и выполните Ctrl+F5. Запишите итоговое время Load/Finish внизу вкладки Network.

## Что оптимизировано в ПР6

- удалён неиспользуемый пакет `cupertino_icons`;
- не добавлены внешние шрифты;
- release-сборка использует tree shaking Flutter;
- списки не держат лишние копии данных: серверная пагинация из ПР4/ПР5 сохранена.
