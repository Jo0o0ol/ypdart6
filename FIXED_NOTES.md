# Что исправлено в FIXED-версии

1. Убрана опасная глобальная обёртка Navigator в `AdaptiveNavigationShell`.
   Раньше при восстановлении сессии/смене роли GoRouter-поддерево переносилось
   между разными родителями, из-за чего Flutter Web мог падать красным экраном.
2. Адаптивная навигация перенесена в `ShellRoute` GoRouter.
3. На 360 px предупреждение о неактивности больше не переполняет строку.
4. Формы и диалоги получили безопасную ширину на узких окнах.
5. Поля года/страниц в форме книги перестраиваются в одну колонку на узком окне.
6. Стартовая HTML-заглушка имеет резервное снятие, чтобы не перекрывать приложение.

## Запуск

Терминал 1:

```bat
node api\mock-server.js --port 8080 --origin http://localhost:5555
```

Терминал 2:

```bat
flutter clean
flutter pub get
flutter run -d chrome --web-port=5555 --no-web-resources-cdn --dart-define=API_BASE_URL=http://localhost:8080/api
```

Если браузер держит старую сборку, после запуска нажмите `Ctrl+F5`.
